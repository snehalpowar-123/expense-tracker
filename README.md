# Expense Tracker - Java Backend Project

A secure and scalable Expense Management System built with Java, Spring Boot & MySQL.

Designed as part of MBS Global & ServiceNow assignment to demonstrate backend fundamentals, clean code and DevOps integration.

### 🚀 Features
- Add / Edit / Delete daily expenses
- Category-wise tracking (Food, Travel, Bills)
- Monthly summary & reports
- Secure REST APIs

### 🛠 Tech Stack
- Java 17, Spring Boot
- MySQL Database
- Maven, Git, GitHub
- Jenkins Ready for CI/CD

### ▶ How to Run
1. Clone repo: git clone https://github.com/snehalpowar-123/expense-tracker.git
2. Open in IntelliJ IDEA
3. Configure MySQL in application.properties
4. Run: mvn spring-boot:run
